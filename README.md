# 계약서 AI 분석기

계약서/약관을 붙여넣거나 파일(PDF/이미지)을 업로드하면 위험 조항을 자동으로 분석해주는 웹 도구입니다.

## 기능
- 텍스트 붙여넣기 또는 PDF/이미지 파일 업로드
- 근로계약서, 임대차계약서, 서비스 이용약관, 프리랜서계약서 자동 분류
- 30여 개 규칙 기반 위험 조항 탐지 (🚨위험 / ⚠️주의 / ✅양호)
- 한국어 OCR 지원 (Tesseract.js)
- 완전 로컬 처리 — 어떠한 정보도 서버에 저장되지 않음

## 배포
GitHub Pages로 배포되어 있습니다.

## 기술 스택
- 순수 HTML/CSS/JavaScript (프레임워크 없음)
- PDF.js — PDF 텍스트 추출
- Tesseract.js — 한국어 OCR
